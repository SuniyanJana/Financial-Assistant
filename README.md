# 💰 Financial Assistant

A full-stack personal finance management web application that helps users track expenses, manage investments, set financial goals, and monitor their overall financial health.

The application is built using **React.js** for the frontend and **Node.js, Express.js, and MongoDB** for the backend and database.

---

## 📌 Overview

**Financial Assistant** is designed to provide users with a centralized platform for managing their personal finances.

Users can create an account, track their expenses, monitor investments, set financial goals, and analyze their financial activities through an interactive dashboard.

The project follows a full-stack architecture where the React frontend communicates with the Node.js and Express.js backend through REST APIs, while MongoDB is used for persistent data storage.
